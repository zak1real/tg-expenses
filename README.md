# Монетка — Telegram Mini App для учёта расходов

Расходы и доходы по месяцам, лимит бюджета с подсказкой «сколько можно тратить в день», круговая диаграмма по категориям (нажатие на категорию фильтрует список), история операций по дням. Чистые HTML, CSS и JS, без сборки и без сервера.

Данные хранятся в **облаке Telegram** (CloudStorage): у каждого пользователя свои, доступны с любого его устройства. В обычном браузере они лежат в localStorage. При первом запуске приложение заполняется примером за два месяца. Пример можно заменить или удалить в настройках (кнопка справа вверху).

## Структура

```
tg-expenses/
├── index.html      # Разметка
├── css/style.css   # Стили (цвета через переменные темы Telegram)
└── js/
    ├── config.js   # Название, цвет, валюта, бюджет, категории — ВСЁ, что меняется под клиента
    ├── storage.js  # Хранилище: CloudStorage Telegram + localStorage (тот же файл в tg-habits)
    └── app.js      # Логика: операции, статистика, диаграмма, пример данных
```

## Как переделать под другого клиента

Правится только [js/config.js](js/config.js):

- `name`, `tagline`, `logo` (эмодзи), `accent` (фирменный цвет), `currency`;
- `budget` — лимит на месяц по умолчанию (0 — без лимита);
- `expenseCategories` и `incomeCategories` — категории: `id`, `title`, `emoji`, `color`. Если поменять `id` у категории, уже сохранённые операции с ней попадут в «Другое».

Пример данных собирается в `demoOps()` в [js/app.js](js/app.js).

## Локальный просмотр

Открыть `index.html` в браузере, удобнее в режиме телефона в DevTools (F12 → иконка телефона).

## Публикация и подключение к боту

1. На GitHub создать репозиторий `tg-expenses` и загрузить содержимое папки через *Add file → Upload files*, сохранив папки `css/` и `js/`. Затем включить *Settings → Pages → Deploy from branch → main*. Адрес будет `https://zak1real.github.io/tg-expenses/`.
2. В [@BotFather](https://t.me/BotFather): `/newbot` создаёт бота, затем `/mybots` → бот → *Bot Settings → Menu Button* → указать адрес из шага 1.

CloudStorage работает только у ботов. Если открыть приложение по прямой ссылке в браузере, данные останутся в localStorage.

## Что можно добавить в рабочей версии

- Ввод расходов сообщением боту («кофе 250»). Для этого нужен сервер, как в `tg-habits-bot`.
- Выгрузка в Excel/CSV, общий бюджет на семью, повторяющиеся платежи.
